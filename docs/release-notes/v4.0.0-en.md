# LocationSpoofer 4.0.0

> The first stable release of this modified version: a new no-root mode, spoofed locations only for target apps, and your own map keys.
>
> The APKs were updated on November 4, 2026 with theme settings and reorganised Features and Settings pages. The version number is unchanged, so an installed 4.0.0 will not prompt for an update. Download the APK and install it over the old one.

## Overview

The original project, [HuangZhuoRui/LocationSpoofer](https://github.com/HuangZhuoRui/LocationSpoofer), has been archived, and this version is a modification of its 3.0.0 source. These notes list every change since the original 3.0.0; the two earlier previews have been removed.

What has been tested:

- **Root mode**: on a Pixel 8 Pro (Android 17), fixed-point spoofing, route spoofing and returning to the real location after stopping. Wi-Fi, cell, Bluetooth and step spoofing have not been fully verified
- **No-root mode**: on a Pixel 8 Pro and a vivo V2307A (OriginOS 6, Android 16), fixed-point spoofing, routes and the floating joystick. WeChat did not follow in testing
- **Theme and page changes**: on these two phones in no-root mode, with AMap only. In Root mode only the check pages were viewed and spoofing was not rerun. The predictive back animation has not been confirmed on the vivo

No other devices have been tested. See "Settings → Run mode and adaptation → Full adaptation progress" in the app.

## Changes

### No-root mode

- **Spoofing without root**: works through the system mock location API. It is used automatically when the LSPosed module is not active, and rooted phones can force it under "Settings → Run mode and adaptation"
- **Setup guide**: if the app is not selected as the mock location app, a dialog explains the steps and opens developer options
- **vivo support**: vivo freezes background apps, so AMap returns to the real location after a few seconds. Once permission requests finish, the app asks you to allow high background power use and opens that settings page. The prompt returns on every start until you tap Open settings
- **Interruption warning**: if the system paused the app and interrupted spoofing, it tells you why once it resumes
- **Limits**: the system marks locations as mock; every app receives the spoofed location; Wi-Fi, cell, Bluetooth, satellites and steps are not spoofed; WeChat uses Tencent location and may not follow

### Theme

- **Theme settings**: under "Settings → Appearance and language → Theme" you can choose dark mode, turn liquid glass on or off and set its strength, switch between a floating and a docked bottom bar, set the page scale and turn predictive back on or off
- **Automatic size**: the first time the app opens, it works out a size that suits the screen and uses it as 100%. You can then make it larger or smaller
- **Predictive back**: on Android 14 and later, the page shrinks with your finger and shows the previous page as you swipe

### Spoofing

- **Per-app delivery** (Root mode): each receiver gets its own copy, so target apps get the spoofed location and other apps keep the real one. Turning spoofing off or removing an app takes effect immediately, without restarting the app
- **Google Maps**: no longer jumps back to the real location and follows long-distance jumps right away. During route spoofing, apps opened before the route started also follow it
- **Back to the real location after stopping**: the app finds the real location through Baidu network location, spoofs there for 5 seconds and then stops, so Google Maps returns even indoors (needs a Baidu key). This also works if Google Maps was closed while stopping
- **Stay where the route stopped**: a new route setting keeps fixed-point spoofing at the spot where a route was stopped midway
- **Satellites and Bluetooth**: satellite status is packed for the current Android version and rewritten only for target apps; real Bluetooth scan results are blocked only for target apps
- **Per-app coordinate systems take effect**: coordinate systems set under "Configure app coordinate systems" now also apply at the system service layer
- **Map position on open**: AMap no longer stays in Beijing when the app opens without spoofing, and reopening the app while spoofing no longer jumps the map to Beijing

### Maps and data

- **Your own keys**: AMap and Baidu keys are no longer built in. Enter your own under "Settings → Map Configuration"; the page lets you copy the package name and signing SHA1 and explains how to apply
- **Route planning**: Baidu and Google route planning in addition to AMap, with walking and driving modes. When only a Baidu key is filled in, "Auto" uses Baidu
- **Environment collection**: works without an AMap key; point collection records a single point per session and uses GPS outdoors; counters show distinct devices
- **Data source tokens**: checked online on save, with the result shown; WiGLE only accepts the Encoded for use value from the account page
- **Every online lookup reports its result**: WiGLE / OpenCellID lookups report how many records were found, no records nearby, an invalid token, an exhausted quota or a network failure
- **No more made-up Wi-Fi**: random fake Wi-Fi is no longer generated when a lookup finds nothing

### Usability

- **Stop button in the notification**: works even when the app is closed, and stops exactly like the in-app button
- **Updates without a reboot**: in-place updates hot-reload the module; only the first enable or a reinstall needs a reboot
- **Update check**: now reads this repository's releases
- **Reorganised pages**: "Info" is now "Settings". The Features page is split into Environment data, Spoofing settings, and Import and export. Data source tokens and motion realism moved to the Features page. Run mode and system adaptation are now one page, "Run mode and adaptation", which shows the checks for the current mode
- **Simpler UI**: removed the root-scheme, vendor-scheme and keep-alive settings that had no effect; removed Arabic so English and Chinese text match one to one; restored the original crosshair icon; new launch screen
- **Import and export**: settings now include the items that were missing, and can also carry theme settings, map keys and data source tokens. Keys and tokens are unticked by default on export
- **Under the hood**: JDK 25, Kotlin 2.4, AGP 9.3, Android 17 SDK, Baidu Map SDK 8.x; deprecated APIs replaced and unused code removed

## Installation

The [v4.0.0 Release page](https://github.com/Lili679280/LocationSpoofer/releases/tag/v4.0.0) provides:

- `LocationSpoofer-4.0.0-arm64-v8a.apk`: for most phones
- `LocationSpoofer-4.0.0-armeabi-v7a.apk`: for older 32-bit phones

Requires Android 8.0 or later.

- **Root mode**: needs root (KernelSU / APatch / Magisk) and LSPosed (API 101 or later). Enable the module in LSPosed, check System Framework, Phone and Bluetooth in its scope, and reboot once
- **No-root mode**: select this app as the mock location app in developer options. vivo phones must also allow high background power use

Coming from a preview: install over it.

Coming from the original 3.x: this is a separate app with its own package name, so it installs alongside the original. Disable the original module in LSPosed and enable this one.

## Map keys

AMap, Baidu and Google keys are bound to the app's package name and signing SHA1. When applying for a key, use:

```text
Package name: com.lili679280.locationspoofer
SHA1: ED:C6:C3:74:A5:53:82:16:A7:F7:ED:86:13:B6:40:D5:B9:9D:CB:CA
```
