# LocationSpoofer 4.0.0

> 修改版的第一个正式版：新增免 Root 模式，只有目标应用拿到模拟位置，地图 Key 自己填写。

[English →](https://github.com/Lili679280/LocationSpoofer/blob/main/docs/release-notes/v4.0.0-en.md)

---

## 概览

原项目 [HuangZhuoRui/LocationSpoofer](https://github.com/HuangZhuoRui/LocationSpoofer) 已经归档，这个版本是在它的 3.0.0 源码上修改的。这里列出相对原版 3.0.0 的全部变化，之前的两个预览版已经删除。

实测情况：

- **Root 模式**：Pixel 8 Pro（Android 17）上测过定点模拟、路线模拟和停止后回到真实位置；Wi-Fi、基站、蓝牙、计步模拟还没有完整验证
- **免 Root 模式**：Pixel 8 Pro 和 vivo V2307A（OriginOS 6，Android 16）上测过定点、路线和悬浮摇杆；微信实测不跟随

其他机型都还没有测过，可以在软件的「信息 → 系统适配 → 完整适配进度」查看。

## 更新内容

### 免 Root 模式

- **不用 Root 也能模拟**：通过系统的模拟位置接口工作，LSPosed 模块没生效时自动使用；有 Root 的手机也可以在「信息 → 运行模式」里强制使用
- **设置引导**：没选「模拟位置信息应用」时会弹出步骤说明，可以直接跳到开发者选项
- **vivo 适配**：vivo 会冻结后台的软件，几秒后高德就回到真实位置。权限申请结束后会提示允许后台高耗电，并直接跳到设置页；没点过「去设置」就每次启动都提示
- **模拟中断提示**：系统暂停过本软件、位置推送中断时，恢复后会提示原因
- **限制**：系统会给位置加上「模拟」标记；所有应用都会收到模拟位置；不模拟 Wi-Fi、基站、蓝牙、卫星和计步；微信走腾讯定位，可能不跟随

### 模拟效果

- **按应用分发位置**（Root 模式）：给每个接收方单独发一份，目标应用拿到模拟位置，其他应用照常拿到真实位置；关掉模拟或把应用移出名单后立即生效，不用重启应用
- **谷歌地图**：不会再跳回真实位置，远距离切换后马上跟随；路线模拟时，模拟开始前就打开的 App 也会跟着走
- **停止后回到真实位置**：停止后先用百度网络定位找到真实位置，在那里模拟 5 秒再停，室内也能让谷歌地图回到原位（需要百度 Key）；谷歌地图关着时停止，之后打开也会回到原位
- **路线停止后留在原地**：路线设置里新增开关，打开后中途停止会在停下的地方继续定点模拟
- **卫星与蓝牙**：卫星状态按当前 Android 版本打包，只改写目标应用；蓝牙只对目标应用屏蔽真实扫描结果
- **应用坐标系设置生效**：「配置应用坐标系」给单个应用指定的坐标系在系统服务层也会生效
- **地图打开时的位置**：不在模拟时打开软件，高德不会再停在北京；模拟中关掉界面再打开，地图也不会跳到北京

### 地图与数据

- **Key 自己填**：不再内置高德、百度 Key，在「信息 → 地图配置」里填写；页面顶部可以复制包名和签名 SHA1，并附申请说明
- **路线规划**：在高德之外新增百度和谷歌路线规划，可选步行或驾车；只填了百度 Key 时，「自动选择」会用百度
- **环境采集**：没有高德 Key 也能采集；点位采集一次只记一个点，室外用 GPS 定位；计数显示不重复的设备数
- **环境数据源 Token**：保存时联网检测并显示结果；WiGLE 只能填账户页的 Encoded for use
- **联网查询都有提示**：从 WiGLE / OpenCellID 获取数据时，会提示查到几条、附近没有记录、Token 无效、次数用完或网络失败
- **不再编造 Wi-Fi**：查不到数据时不再随机生成假 Wi-Fi

### 使用体验

- **通知栏停止按钮**：界面关着也能停，效果和在软件里停止一样
- **更新不用重启**：覆盖安装后模块自动热重载，只有第一次启用或卸载重装才需要重启
- **检查更新**：改为从本仓库获取
- **信息页改版**：新增「运行模式」，「系统适配」按当前模式显示对应的检测项
- **界面精简**：去掉不起作用的 Root 方案、厂商方案、后台保活设置；去掉阿拉伯语，中英文文字一一对应；换回原来的准星图标；新的启动画面
- **导出配置**：补全了之前漏掉的几项设置
- **底层更新**：JDK 25、Kotlin 2.4、AGP 9.3、Android 17 SDK、百度地图 SDK 8.x；替换已废弃的接口，清理无用代码

## 安装

[v4.0.0 Release 页面](https://github.com/Lili679280/LocationSpoofer/releases/tag/v4.0.0)提供：

- `LocationSpoofer-4.0.0-arm64-v8a.apk`：绝大多数手机用这个
- `LocationSpoofer-4.0.0-armeabi-v7a.apk`：32 位老机型

需要 Android 8.0 以上。

- **Root 模式**：需要 Root（KernelSU / APatch / Magisk）和 LSPosed（API 101 以上）。在 LSPosed 里启用模块，作用域勾选系统框架、电话、蓝牙，然后重启一次
- **免 Root 模式**：在开发者选项里把本软件选为「模拟位置信息应用」；vivo 手机还要允许后台高耗电

从预览版升级：直接覆盖安装。

从原版 3.x 换过来：包名不同，这是一个新 App，可以和原版同时安装。在 LSPosed 里关掉原版模块、启用这一个即可。
