# LocationSpoofer 4.0.0 Preview 2

> Rewritten location delivery so only target apps get the spoofed location; data source tokens are checked on save, and every online lookup reports its result.

[简体中文 →](https://github.com/Lili679280/LocationSpoofer/releases/tag/v4.0.0-preview.2)

---

## Overview

This release mainly rewrites how spoofed locations are delivered and fixes issues found in code review. It is still a preview and has only been tested on a Pixel 8 Pro (Android 17); Wi-Fi, cell, Bluetooth and step spoofing have not been fully verified yet.

## Changes

- **Per-app location delivery**: the system's location data is no longer rewritten in place. Each recipient gets its own copy: target apps get the spoofed location and every other app keeps the real one. Turning spoofing off or removing an app from the list takes effect immediately, without restarting the app
- **Apps outside the list are unaffected**: the once-a-second injected GNSS fix is tagged so non-target apps skip it, and reading the last known location returns the last real fix
- **Satellite status fixes**: satellite IDs and flags are packed for the running Android version, and the older Android 11 callback is handled; only target apps get rewritten satellite status, and raw measurements are blocked only for target apps instead of every app
- **Bluetooth**: real scan results are blocked only for target apps (previously "all apps" mode left every app unable to scan); scans started before spoofing are taken over too
- **Per-app coordinate systems take effect**: the coordinate system set for an app under "Configure App Coordinate System" now also applies in the system services
- **AMap opens at the real location**: previously, opening the app while not spoofing left AMap on Beijing until you tapped the location button
- **Environment data source tokens**:
  - Saving checks the tokens online and shows on the page whether each one is valid
  - WiGLE accepts either "Encoded for use" from your account page or "API name:API token"
- **Every online lookup reports its result**: WiGLE / OpenCellID lookups say how many records were found, or that there are none nearby, the token was rejected, the quota is used up, or the network failed
- **No more made-up Wi-Fi**: when WiGLE found nothing or the token was invalid, the app used to save 10 random fake Wi-Fi networks into the collected data; this is removed
- **Info tab redesign**: icon on top with the name and tagline below; each setting is its own card with a short description, spaced like the Features tab
- **Settings export**: now includes the settings it used to miss
- **Docs**: the README covers Tasker / MacroDroid broadcast control, the limits of "all apps" mode, and how to fill in WiGLE and OpenCellID tokens; LICENSE now holds the full GPL-3.0 text

## Installation

The [v4.0.0-preview.2 Release page](https://github.com/Lili679280/LocationSpoofer/releases/tag/v4.0.0-preview.2) provides:

- `LocationSpoofer-4.0.0-preview.2-arm64-v8a.apk`: for most phones
- `LocationSpoofer-4.0.0-preview.2-armeabi-v7a.apk`: for older 32-bit phones

Requires Android 8.0 or later, root (KernelSU / APatch / Magisk) and LSPosed (API 101 or later).

Upgrading from Preview 1: install over it; the module hot-reloads, no reboot needed. For a first install, enable the module in LSPosed, check System Framework, Phone and Bluetooth in its scope, and reboot once.
