# LocationSpoofer 4.0.0 预览版 2

> 重写定位分发：只有目标应用拿到模拟位置；环境数据源 Token 保存时检测，联网查询结果都有提示。

[English →](https://github.com/Lili679280/LocationSpoofer/blob/main/docs/release-notes/v4.0.0-preview.2-en.md)

---

## 概览

这一版主要重写了模拟位置的分发方式，并修了审查中发现的问题。仍是预览版，目前只在 Pixel 8 Pro（Android 17）上实测过；Wi-Fi、基站、蓝牙、计步模拟还没有完整验证。

## 更新内容

- **按应用分发位置**：不再直接改写系统里的定位数据，而是给每个接收方单独发一份——目标应用拿到模拟位置，其他应用照常拿到真实位置；关掉模拟或把应用移出名单后立即生效，不用重启应用
- **名单外应用不受影响**：每秒注入的卫星定位会做标记，名单外的应用会跳过它；读取"上次位置"时拿到的是上次的真实位置
- **卫星状态修正**：按当前 Android 版本打包卫星编号和标志位，兼容 Android 11 的旧版回调；只改写目标应用的卫星状态，原始测量数据也只对目标应用屏蔽，不再影响所有应用
- **蓝牙**：只对目标应用屏蔽真实扫描结果（之前"全部应用"模式下所有应用都扫不到蓝牙）；模拟开始前就在扫描的应用也会被接管
- **应用坐标系设置生效**：「配置应用坐标系」里给单个应用指定的坐标系现在在系统服务层也会生效
- **高德地图打开时在真实位置**：之前不在模拟时打开软件，高德会停在北京，要点一下定位按钮才回来
- **环境数据源 Token**：
  - 点击保存会联网检测，并在页面上显示每个 Token 是否有效
  - WiGLE 可以填账户页的 Encoded for use，也可以填「API 名:API Token」
- **联网查询都有提示**：从 WiGLE / OpenCellID 获取数据时会提示查到几条、附近没有记录、Token 无效、次数用完或网络失败
- **不再编造 Wi-Fi**：WiGLE 查不到或 Token 无效时，以前会随机生成 10 个假 Wi-Fi 存进采集数据，现在去掉了
- **信息页改版**：图标在上、名称和简介在下；各项设置一项一张卡片，带简短说明，间距和「功能」页一致
- **导出配置**：导出的设置补全了之前漏掉的几项
- **文档**：README 补充 Tasker / MacroDroid 广播控制、"全部应用"模式的限制、WiGLE 与 OpenCellID Token 的填法；LICENSE 改为完整的 GPL-3.0 文本

## 安装

[v4.0.0-preview.2 Release 页面](https://github.com/Lili679280/LocationSpoofer/releases/tag/v4.0.0-preview.2)提供：

- `LocationSpoofer-4.0.0-preview.2-arm64-v8a.apk`：绝大多数手机用这个
- `LocationSpoofer-4.0.0-preview.2-armeabi-v7a.apk`：32 位老机型

需要 Android 8.0 以上、Root（KernelSU / APatch / Magisk）和 LSPosed（API 101 以上）。

从预览版 1 升级：直接覆盖安装，模块会自动热重载，不用重启。第一次安装的话，在 LSPosed 里启用模块，作用域勾选系统框架、电话、蓝牙，然后重启一次。

## 安全提示

本软件会 Hook 系统的定位、Wi-Fi、基站和蓝牙服务，需要 Root 和 LSPosed。仅用于学习研究和合法的测试，不要用于打卡、考试等违反规定或平台协议的用途。报告问题请查看 [SECURITY.md](https://github.com/Lili679280/LocationSpoofer/blob/main/SECURITY.md)。本项目基于 [GPL-3.0](https://github.com/Lili679280/LocationSpoofer/blob/main/LICENSE) 协议开源。
