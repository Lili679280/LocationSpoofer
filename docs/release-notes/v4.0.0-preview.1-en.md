# LocationSpoofer 4.0.0 Preview 1

> The first separate release of this modified LocationSpoofer: bring your own map keys, Baidu and Google route planning, and Pixel adaptation.

[简体中文 →](https://github.com/Lili679280/LocationSpoofer/releases/tag/v4.0.0-preview.1)

---

## Overview

The original project, [HuangZhuoRui/LocationSpoofer](https://github.com/HuangZhuoRui/LocationSpoofer), has been archived. This version is a modification of its 3.0.0 source and is the first one released separately.

This is a preview and may have problems. So far it has only been tested on a Pixel 8 Pro (Android 17): fixed-point spoofing, route spoofing and returning to the real location after stopping. Other devices, and Wi-Fi / cell / Bluetooth / step spoofing, have not been verified yet. The stable release is planned to add a no-root mode.

## Changes

- **Your own keys**: AMap and Baidu keys are no longer built in. Enter your own under "Info → Map settings"; the top of that page lets you copy the package name and signing SHA1 and explains how to apply for keys
- **Route planning**: Baidu and Google route planning in addition to AMap, with walking and driving modes. When only a Baidu key is filled in, "Auto" uses Baidu
- **Pixel adaptation**: Google Maps no longer jumps back to the real location; it follows long-distance jumps right away; during route spoofing, apps that were opened before the route started also follow it
- **Back to the real location after stopping**: after stopping, the app finds the real location through Baidu network location, spoofs there for 5 seconds and then stops, so Google Maps returns to the real position even indoors (needs a Baidu key)
- **Faster startup location**
- **Updates without a reboot**: in-place updates hot-reload the module; only the first enable or a reinstall needs a reboot
- **Simpler UI**: removed the root-scheme, vendor-scheme and keep-alive settings that had no effect; removed Arabic so English and Chinese text match one to one; restored the original crosshair icon without the black ring; new launch screen
- **Under the hood**: JDK 25, Kotlin 2.4, AGP 9.3, Android 17 SDK, Baidu Map SDK 8.x; deprecated APIs replaced and unused code removed
- **Update check**: now reads this repository's releases; preview builds receive preview updates by default

## Installation

The [v4.0.0-preview.1 Release page](https://github.com/Lili679280/LocationSpoofer/releases/tag/v4.0.0-preview.1) provides:

- `LocationSpoofer-4.0.0-preview.1-arm64-v8a.apk`: for most phones
- `LocationSpoofer-4.0.0-preview.1-armeabi-v7a.apk`: for older 32-bit phones

Requires Android 8.0 or later, root (KernelSU / APatch / Magisk) and LSPosed (API 101 or later). After installing, enable the module in LSPosed, check System Framework, Phone and Bluetooth in its scope, and reboot once.

Coming from the original 3.x: the signature is different, so uninstall the original app first.

## Map keys

AMap, Baidu and Google keys are bound to the app's package name and signing SHA1. When applying for a key, use:

```text
Package name: com.vincenthzr.locationspoofer
SHA1: ED:C6:C3:74:A5:53:82:16:A7:F7:ED:86:13:B6:40:D5:B9:9D:CB:CA
```
